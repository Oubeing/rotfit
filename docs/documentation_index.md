## 📋 快速参考

### 核心配置项
```json
{
  "rotation": {
    "mode": "discrete|continuous",
    "vectors": [[x,y,z], ...],
    "fixed_axes": {"in": {"idx": [x,y,z]}},
    "fixed_order": {"in": {"pos": idx}}
  },
  "training": {
    "epochs": 数值,
    "learning_rate": 数值
  }
}
```

### 数据格式
- CSV/Excel文件
- 列名必须以"in"和"out"开头
- 角度使用度数单位

### 常见问题
- **收敛慢**: 降低学习率，增加训练轮数
- **NaN错误**: 检查数据范围，程序已有处理机制
- **内存不足**: 使用CPU模式或减少数据量

## 🔧 程序文件
- `1.py` - 主程序

## 💡 提示
- 建议先用小数据集测试配置
- 多探测向量可以提高拟合精度
- 固定约束可以利用先验知识
- 离散模式适合标准旋转轴，连续模式更灵活

有问题请参考相应文档或检查配置文件格式！
